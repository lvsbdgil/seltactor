# Стек для прототипа и питчинга

Выбор: React + TypeScript + Vite для фронтенда, Python + FastAPI для API анализа.

## Что используется сейчас

| Инструмент | Роль | Почему подходит |
| --- | --- | --- |
| TypeScript | Язык интерфейса | Типы материалов, состояний загрузки и отчётов облегчают подключение API |
| React 19 | Библиотека интерфейса | Общая логика загрузки и отчётов в трёх независимых визуальных концепциях |
| Vite 7 | Сервер разработки и сборка | Быстрый локальный запуск и статическая сборка для демонстрации |
| CSS variables | Стили и темы | Разные композиции и палитры без тяжёлой UI-зависимости |
| Lucide React | SVG-иконки | Единая и масштабируемая графика |
| Playwright | Проверки браузера | Основной сценарий и отсутствие горизонтального скролла на 375/768/1024/1440 px |

React — библиотека, Vite — сборщик и сервер разработки; вместе это выбранная основа SPA. Next.js подходит, если появятся публичный индексируемый сайт, серверные страницы и сложная авторизация. Для локального кабинета загрузки эти возможности сейчас не нужны. Vue 3 + TypeScript + Vite также подходит; React выбран для текущей реализации и последующего развития компонентов.

## Сервер анализа и дальнейшее развитие

- Python + FastAPI: приём файлов, контракты API, задачи обработки.
- FFmpeg: извлечение кадров из видео; OpenCV: подготовка и контроль качества снимков.
- Модель компьютерного зрения или внешний API: после испытаний на размеченных данных. Прототип не подтверждает распознавание клопа по аэрофотосъёмке.
- Фоновая очередь для длительных задач; прогресс через polling/SSE.
- Объектное хранилище для оригиналов и кадров; PostgreSQL для полей, обследований и результатов. Для самого первого пилота возможна SQLite; конкретное решение зависит от развёртывания и параллельных задач.
- При необходимости настоящей геокарты — MapLibre GL JS и отдельно выбранный источник картографических тайлов. Наличие GPS, точность границ и ортофотоплан требуют отдельной проверки.

FastAPI, официальный SDK OpenAI, Pillow и FFmpeg реализованы в текущем пайплайне. Постоянное хранилище, распределённая очередь и настоящая геокарта остаются следующими этапами.
