# SELTACTOR · Рост

Выбранная концепция «Рост» в тёмной природной палитре. Сервис для загрузки съёмки с дрона и предварительного визуального анализа материалов через OpenAI.

## Локальный запуск

Node.js 22.12+ и Python 3.12+. Для видео нужны FFmpeg и ffprobe.

```bash
npm ci
python3.12 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements.lock
cp backend/.env.example backend/.env
```

Укажите собственный `OPENAI_API_KEY` в `backend/.env`. Ключ не должен попадать во фронтенд, переменные `VITE_*` или Git. Модель задаётся серверной переменной `OPENAI_MODEL`.

Запустите в двух терминалах из корня проекта:

```bash
npm run dev:api
```

```bash
npm run dev -- --port 5173 --strictPort
```

- http://localhost:5173/ — основной сайт, тёмный «Рост»
- http://localhost:8000/docs — интерактивная документация API

Без ключа доступен отдельный демопример с синтетическим отчётом. Настоящий анализ без ключа возвращает понятную ошибку; синтетический отчёт за результат ИИ не выдаётся. Вызовы OpenAI тарифицируются в вашем API-проекте.

## Доступ

Без входа доступны два подготовленных примера с учебными фото, видео и отчётами. Собственная загрузка и OpenAI-анализ доступны только администратору; API проверяет сессию на сервере.

На этой локальной установке логин — `admin`, пароль — в игнорируемом файле `backend/admin-credentials.txt`. Вход — кнопка в правом верхнем углу сайта. Подробнее: [docs/AUTH.md](docs/AUTH.md).

## Обработка

Выбор и drag-and-drop фото/видео → выбор поля, культуры и даты → локальный FastAPI → проверка и подготовка изображений / выборка кадров FFmpeg → OpenAI Responses API со строгой схемой результата → отчёт с наблюдениями, источниками и ограничениями → скачивание PDF.

До 12 файлов, фото до 50 МБ, видео до 2 ГБ, набор до 4 ГБ. Не более 24 изображений в запросе к модели. Оригиналы удаляются с локального сервера после обработки. История задач — временная, в памяти процесса. Подробности, ограничения и точные параметры: [docs/PIPELINE.md](docs/PIPELINE.md).

Это локальный прототип: реализован вход одного администратора; постоянного хранилища и распределённой очереди пока нет. Его нельзя публиковать в интернете без отдельной подготовки. Геопривязка, ортофотоплан и определение численности вредителей не реализованы; достоверность агрономических выводов не подтверждена полевыми испытаниями. Схема поля и история прежних обследований являются иллюстрациями. Решение о действиях принимает агроном.

## Проверки и сборка

```bash
npm run build
npm run test:ui          # фронтенд должен быть запущен на 5173
npm run test:pipeline-ui # интеграция UI с подменёнными API-ответами, без расходов OpenAI
npm run test:auth-ui     # локальный вход/выход, нужны backend и локальный файл данных админа
npm run test:pdf         # длинный PDF, кириллица, автоматическая пагинация
backend/.venv/bin/python -m pytest backend/tests -q
```

Playwright использует Chrome на macOS. На других системах предварительно `npx playwright install chromium`. Проверки сервера используют искусственные изображения/видео и HTTP-подмену OpenAI; платные запросы не выполняются.

Для показа интерфейса без интернета есть локальные шрифты, SVG-иллюстрации и демопример. Реальный анализ требует интернета и настроенного OpenAI API.

## Стек

React 19 + TypeScript + Vite 7; CSS-переменные тем; Lucide React. Сервер: Python + FastAPI, Pillow, FFmpeg, официальный SDK OpenAI. [Обоснование выбора](docs/STACK.md).

Приватный репозиторий: https://github.com/lvsbdgil/seltactor

## Проверка реального ключа

Ключ подключён локально и сохранён в GitHub Actions Secret `OPENAI_API_KEY`. Проверка 2026-11-05 дошла до OpenAI, который вернул HTTP 429: `credit_balance_exhausted` / `insufficient_quota`. Успешный реальный анализ пока не подтверждён: требуется восстановить доступный баланс API-проекта. Демопримеры и вход администратора работают независимо от баланса. Исходный файл ключа и локальные данные входа исключены из Git и закрыты в Vite.

## Сервер

Сайт: https://seltavir.alexanderlych.ru. Развёртывание: два Docker-контейнера (Caddy и FastAPI/FFmpeg) за существующим Caddy-шлюзом. Инструкция: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

Отчёты выгружаются в PDF с встроенным кириллическим шрифтом, переносами строк и автоматической пагинацией. Создание PDF выполняется в браузере; данные не пересылаются дополнительному сервису. На сайте оставлен только выбранный третий тёмный вариант.
